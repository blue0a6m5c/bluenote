# Security policy

## Supported versions

BlueNote is currently an early-stage project without a stable release. Security fixes are applied to the latest code on the `bluenote` branch; older commits and development branches are not supported versions.

## Reporting a vulnerability

Please report suspected BlueNote vulnerabilities privately through [GitHub's security advisory form](https://github.com/blue0a6m5c/bluenote/security/advisories/new). Include the affected commit or version, configuration, reproduction steps, impact, and any suggested mitigation.

Do not include vulnerability details in a public issue. If the private reporting form is unavailable, open a public issue containing no sensitive details and ask the maintainer to arrange a private reporting channel.

BlueNote is derived from WriteFreely. Maintainers will coordinate with upstream when a report affects shared code. If a vulnerability is known to affect unmodified WriteFreely rather than BlueNote-specific code, it may also be reported through [WriteFreely's security page](https://github.com/writefreely/writefreely/security).

BlueNote does not currently promise a fixed response or remediation time. The project will acknowledge and assess reports as maintainer availability permits.
